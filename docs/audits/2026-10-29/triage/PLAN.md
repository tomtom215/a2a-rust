**Delivery, decided 2026-10-31 (see `DECISIONS.md` section 0).** One branch and one pull request per theme, each named `claude/jolly-wozniak-zc1vbe-<theme>` and started from `main`, never stacked. CI takes 60 to 90 minutes a pull request and has not passed first time for a long while, so the rule is: keep the branches to disjoint files so they merge in any order, and run every gate locally first, `cargo mutants --in-diff` included, so CI is a confirmation and not the first run. Where two themes would touch the same file, the change goes in the first; the other waits for it. A shared file that every pull request wants (`CHANGELOG.md`, this audit's README) is edited next to the related existing entry, not at the end of a list, so two pull requests do not collide on the same line.

**Breaking-batch candidates for pull request 10** (the four chosen, then what the triage found; each is confirmed against `cargo-semver-checks` and gets an upgrade-guide line before it is taken). Chosen: G-10 (`#[non_exhaustive]` on `AgentCard`, `AgentSkill`, `AgentInterface`, `AgentProvider`), G-06 (b) (`tls-rustls` in the server's defaults), G-18 (`ContextId`), G-14 (2) (`Telemetry::init()` quieter). Found: `AgentCard::validate()` returning a typed error that names the skill (today a `const fn` returning `&'static str`, G-07 b); the gRPC `serve_with_shutdown` returning `ServeReport` like the other listeners and the WebSocket one taking `self` (D-GC-4 option 2); `RateLimitConfig::window_secs` becoming a `Duration` (G-15 g); `AgentCard.url`, accepted on input and never emitted, deprecated or removed (G-10); splitting `ClientError::Transport` into configuration and connection loss so the retry classification is honest (N-GD-5, D-09). Default changes that are breaking in behaviour, to be listed in the same upgrade-guide section: WebSocket pings on by default (D-B1); `Retry-After` beyond `max_backoff` returned to the caller (D-10 a); `Profile::Production` refusing in-memory halt and lease stores over a shared task store (E-F13); OTEL values warn instead of aborting (C-08).
